Malpractice

Academic Malpractice
The project will be considered complete only once the final grade for the project course is published on the student dashboard.


Any inappropriate conduct during the project period may be treated as malpractice. This includes, but is not limited to the following:

Sharing code snippets, notebooks, or any project-related material with any other students. This includes students not registered for the project course.
Submitting work that is wholly or partially copied from another student
Allowing another individual to complete any portion of the project on one’s behalf.
Using solutions, code repositories, or notebooks from external sources
Reproducing project outputs that are substantially similar to another student’s work, even if variable names or minor details are altered.

All parties flagged under academic malpractice will be subject to the following penalties:

‘U’ grade in all the courses in the concerned term
Debarred from registering for courses in the subsequent 2 terms
